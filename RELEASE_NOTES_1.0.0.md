# Local Transcriber 1.0.0

First public release of **Local Transcriber by IDEALVISUAL**.

### Highlights
- Fast local transcription with whisper.cpp
- Windows CUDA acceleration when supported
- Raspberry Pi ARM/CPU support
- Unified IDEALVISUAL interface on Windows and Raspberry Pi
- Batch queue with progress and live output
- Resizable queue/live-output area
- Pause, resume and cancel
- Model manager
- FLAC/WAV/MP3 audio preparation
- TXT, SRT and VTT export
- Dark and Light themes
- Raspberry Pi thermal protection

### Privacy
Transcription runs locally on the device.
