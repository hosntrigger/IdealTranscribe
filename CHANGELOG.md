# Changelog

## 1.2.0 UI Preview
- Four live themes with persistent selection: Material Dark, Material Light, Studio Dark, Android Expressive.
- IDEALVISUAL cyan accents and original product and brand marks.
- Real scalable rounded Tk buttons with hover, focus, pressed and disabled states.
- Contrasting model and download dialogs, single model manager and two-line model entries.
- Existing transcription backends, configuration and model storage retained.
- Native OS dialog decorations remain platform-specific. Preview requires Windows and Raspberry Pi acceptance tests.

## 1.1.0
- German and English interface
- persistent UI language selection
- translated main window, dialogs, status messages and model manager
- translated language, performance and audio-preparation display values
- Windows and Raspberry Pi support retained without changing transcription logic


### Release licensing
- public v1.0.0 license set to PolyForm Noncommercial 1.0.0; commercial use requires a separate license


### Release candidate fix
- progress bar/status moved outside the resizable queue/live panes so it stays visible on small screens


## 1.0.0
- first public release
- unified Windows and Raspberry Pi interface
- Windows CPU/CUDA support
- Raspberry Pi ARM/CPU and thermal protection
- model management
- automatic FLAC audio preparation
- batch queue and progress display
- resizable queue/live-output split
- pause/resume/cancel
- Light/Dark themes
- safe close confirmation
- IDEALVISUAL branding and application icon
